# AROMIRE KEHINDE — Portfolio

A modern, responsive one-page portfolio website for **AROMIRE KEHINDE**, Web & App Developer.

Theme: deep black + glowing violet. Built with vanilla HTML, CSS and JavaScript — no build step, no dependencies.

## Sections

- **Hero** — name, role, tagline (DESIGN. DEVELOP. DELIVER.), introduction and developer avatar
- **About Me**
- **My Skills** — HTML, CSS and JavaScript
- **My Services** — Website, Web App and Mobile App Development
- **My Projects** — placeholders, ready for real projects
- **Contact Me** — WhatsApp and email, with clickable buttons and a message form

## Features

- Dark purple / black theme with glowing violet gradients
- Smooth scrolling and scroll-linked navigation highlighting
- Interactive 3D tilt cards and a cursor glow
- Floating avatar card with animated chips and a dashed rotating ring
- Scroll-reveal animations, animated counters and skill bars
- Fully responsive (mobile menu, fluid type and grids)
- Respects `prefers-reduced-motion`

## Run locally

Just open `index.html`, or serve the folder:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Structure

```
index.html        # page markup
css/styles.css    # theme, layout, animations
```
